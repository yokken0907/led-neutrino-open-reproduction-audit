Files in this directory are retained only to preserve analysis history.

They contain interpretations, status documents, workflows, runners, checksum lists, or submission notes that predate the current ReScience C manuscript. Some refer to the withdrawn 39-versus-17 threshold-crossing interpretation or to the withdrawn binary Daya Bay calibration-failure interpretation.
